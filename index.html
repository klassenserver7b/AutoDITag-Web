AutoDITag

Rename, tag and playlist your dance music — right in your browser.

Files never leave your browser. Nothing is uploaded.

1

Music folder

Pick the folder that holds your mp3 files. Sub-folders are ignored.

Drop the folder here

or use the folder picker below

2

Descriptor file

One line per track. Upload the file or paste the text — both work.

A plain text file with the track list.

Format TRACKNUM_TITLE; ARTIST -- DANCE e.g. 01_Voices of Spring; André Rieu -- Wiener Walzer

3

Playlist name

Used as the album tag and as the name of the playlist files.

Optional

Spotify cover art

Add album artwork to every track. Needs your own Spotify app credentials.

The secret stays in your browser and is sent only to Spotify, for the artwork lookup. It is never uploaded to us.
